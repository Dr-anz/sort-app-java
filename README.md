# SortApp Java

Проект реализует сортировку кастомных объектов () с выполнением специальных требований: сортировка чётных/нечётных, стримы, многопоточность, запись в файл.

## Структура

-  — класс  с паттерном Builder и валидацией.
-  — алгоритмы сортировки (без готовых реализаций) и компараторы.
-  — запись данных в файл в режиме добавления.
-  — многопоточный подсчёт вхождений.
-  — ручные тесты без сторонних библиотек.

## Реализованные возможности

- Сортировка по 3 полям (имя, возраст, GPA) через компараторы.
- Задание 1: сортируются только элементы с чётным значением поля; нечётные сохраняют позиции.
- Задание 2: запись отсортированных данных в файл (режим добавления).
- Задание 3: заполнение коллекций через стримы; кастомная коллекция.
- Задание 4: многопоточный подсчёт количества вхождений элемента.

## Как запустить

1. Откройте проект в VS Code ().
2. Запустите класс с ручным тестом (в папке ).
